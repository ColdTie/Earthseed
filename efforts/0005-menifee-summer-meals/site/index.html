Summer meal programs are funded by the USDA and run by school districts and community sites. Any child 18 and under can walk in — no paperwork, no ID, no income test. The meal is free. In Menifee, three programs are running this summer.

USDA Summer Meals Site Finder — tap for details

Tool available
What it is
The USDA runs a nationwide database of all summer meal sites. You can search by zip code to find every participating site near you — including sites not listed here.
How to use it
Text FOOD to 877-877 for a text-based site finder (works on any phone).

Or visit fns.usda.gov/sfsp/sitefinder and search by your zip code (92584, 92585, or 92586 for Menifee).
